Commercialising Modern LEO Plans Using AI Models

Low Earth Orbit (LEO) has been proven to be the most economically viable region for space commercialisation, allowing for telecommunication, Earth observation and in flight manufacturing. AI simulation tools such as those powered by reinforcement learning (RL) allow for more coherent launch dynamics to predict flight paths and reduce testing costs. Despite RL advancements, its application in simulating orbital vehicles commercially remain largely non-existent. The RL model used for the simulation aims to model the flight dynamics of the Falcon 9 rocket to support more efficient mission planning and design.

A graph generated using matplotlib.pyplot using SpaceX-licensed Github data to show the velocity of a Falcon 9 rocket over 565 seconds. This demonstrates the data that our RL model is trained upon to give a high degree of accuracy.
